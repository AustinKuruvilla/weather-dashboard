# Weather-Dashboard
A weather dashboard that was built with Python and django that shows the current weather conditions and the forecast of next three days for the searched city.
### Main features of the weather dashboard
-Current Weather: View current temperature, weather conditions, and weather-related statistics.
-Three-Day Forecast: Check the upcoming weather forecast.
-City Search: Search for weather information by city name.
-Recent Searches: View and revisit the five most recently searched cities.
-Input Validation: Display an error message when weather information cannot be retrieved for a city.
-Responsive Interface: A styled interface designed to adapt to different screen sizes.
-Automated Tests: Seven Django tests covering the applications behavior.

###Tech stack
Backend:Python, django
Frontend: html, CSS,JS
Database:SQLite
API:Weather API
Testing: Django automated test framework
